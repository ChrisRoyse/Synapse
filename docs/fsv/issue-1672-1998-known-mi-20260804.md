# FSV: known mutual information and fresh scratch isolation (#1672, #1998)

Date: 2026-08-04

## Contract and source of truth

The fixture creates 400 timeline constellations with a balanced boolean anchor. The label is a threshold on the strictly increasing event-time rank, so the answer is known before execution: `H(anchor)=1 bit` and `I(event_time_rank; anchor)=1 bit`. The Source of Truth is the scratch Calyx vault's physical `Base`, `Anchors`, `Assay`, and `Ledger` CF rows, read through a newly opened read-only handle that never held the writer lock.

The fixture now atomically creates its own new directory. It refuses existing paths so a prior vault cannot contaminate a known-answer corpus.

## Diagnosis and research

The remaining #1672 acceptance instrument existed but had never been run. Its persistence claim also relied on computing-call reports, and `create_dir_all` silently accepted a reused/nonempty vault. Exa MCP was live and returned the official Rust filesystem guidance; the built-in web lane independently read it. Rust documents that `create_dir` creates a new empty directory and errors when the path exists, while `create_dir_all` is non-atomic and treats concurrent creation as success:

- <https://doc.rust-lang.org/std/fs/fn.create_dir.html>
- <https://doc.rust-lang.org/std/fs/fn.create_dir_all.html>
