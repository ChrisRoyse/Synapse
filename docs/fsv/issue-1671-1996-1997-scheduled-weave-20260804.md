## Diagnosis

The native Loom implementation, cross-term persistence, graph construction, and abundance readback already existed, but no production scheduler invoked them. Separately, two valid exact structured values were incorrectly presented to cosine geometry:

1. A non-empty vector whose values are all zero has no cosine direction. One such row aborted every other record and slot in the panel.
2. A bounded corpus containing only empty sparse vectors produced an observed support width of zero. The densifier then fabricated `Vec::new()`, which failed later as a zero-dimensional Loom vector.

The fix schedules bounded, watermark-driven panel passes under the existing pressure-aware maintenance admission. It retains exact zero values in `Base`, excludes all-zero vectors only from cosine kNN with slot and CxId evidence, and classifies empty observed sparse support as non-measurable instead of manufacturing a dimension.
